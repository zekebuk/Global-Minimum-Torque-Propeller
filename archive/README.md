# Archive

This folder preserves project history that is not part of the final reproducible thesis workflow.

The final workflow uses only:

- `scripts/`
- `src/prandtl_prop/`
- locked data in `data/`
- regenerated final outputs in `outputs/`

Archived files are retained for traceability and historical context. They should not be included in quick-start commands or cited as final methodology unless a specific archived artifact is proven to have directly produced a final thesis or paper figure/table.

## Contents

- `legacy_scripts/`: older development scripts, earlier solver attempts, deprecated UI code, legacy tests, and historical FEA helpers.
- `exploratory_notebooks/`: exploratory notebook-style work, including MATLAB live scripts.
- `old_outputs/`: superseded generated figures, tables, reports, reference inputs, and scratch outputs that were useful during development but are not part of the locked final workflow.

Every file in this archive should be treated as legacy unless a later audit explicitly promotes it back into the final workflow.
