# Helper Files

This folder holds support material that does not need to sit in the main Code
directory.

The pressure-test utilities for `Geometry_optimization.py` are in
`pressure_tests/`. From the main Code directory, run them with:

```powershell
python .\helper_files\pressure_tests\test_pressure.py
python .\helper_files\pressure_tests\PRESSURE_TEST_REPORT.py
```
