# PF10 arm joint: tapered sliding dovetail

Numbers in this note come from `config/frame.yaml → arm.joint` and the current
`outputs/design_report.md`. The geometry is generated by `src/prandtl_prop/frame/cad/parts.py` (CadQuery) and
`onshape/generated/PF10ModularArm.fs` + `PF10ArmSocket.fs` (Onshape). Both use the same section function
(`geometry.tenon_section` / FeatureScript `tenonSection`), so arm and socket cannot drift apart.

## Cross-section (looking along the arm, toward the body)

```
            top plate (0.3 mm relief: never touches the arm)
   ═══════╤═══════════════════════════════════════╤═══════
   tie    │   ┌─────── tenon (PPA-CF) ───────┐     │ tie
   bolt ─►│ ░░│                              │░░   │◄─ bolt (M3, steel)
          │ ░░│ 0.3 clearance on the straight│░░   │
          │ ░░│ sides: deliberately no contact│░░  │
          │ ░░│        ┌──channel──┐         │░░   │
          │ ░░│        └─────V─────┘         │░░   │
          │ ░░ ╲                            ╱ ░░   │   ← 60° dovetail flanks (30° from vertical)
          │ ░░░░╲__________________________╱░░░░   │      line-on-line = the seat
   ═══════╧═════════ floor (PAHT-CF) ══════════════╧═══════
                     ▲ retention screw (M3, from below, radial slot) into a brass insert in the foot
```

`░` is socket-block material (PAHT-CF). The region directly above each flank is a **compression strut** to
the top plate.

## Why each feature exists

| Feature | Physics / reason |
| --- | --- |
| **Dovetail foot at the bottom** | Thrust bends the tip up, so the tenon pushes *up* near the mouth and *down* near the back. The flanks take the upward reaction and the floor takes the downward one. No bolt passes through the arm. |
| **60° dovetail (30° from vertical)** | Prints unsupported in both parts: the socket prints floor-down and the arm prints top-face-down. Each flank overhangs 30°, well inside the 45° limit. It is also the standard machine-dovetail angle. |
| **Seat = flanks + floor only** | The straight sides have 0.3 mm clearance and the top plate has a 0.3 mm relief. Each degree of freedom then has one contact set, so the joint is not over-constrained and print tolerance cannot make it rattle or bind. |
| **1:25 plan taper per side** | Pushing the arm home wedges the flanks, giving zero play and a preload. Print error becomes axial travel instead of slop: ±0.24 mm of width error ↔ ±3 mm of seat travel (`home_gap`). tan(2.3°) = 0.04 ≪ μ ≈ 0.25, so the wedge self-locks (ratio ≈ 6). |
| **Wider at the mouth** | The cavity only gets wider toward the outside, so the arm always slides out freely. The CAD check sweeps the arm out 2–35 mm with zero interference. |
| **Steel tie bolts in the socket walls** | Upward flank load rises through the socket block *in compression* to the top plate, then returns to the floor in the bolts. Printed layers never see tension, which matters because Z strength is the weak axis of every printed part. |
| **Retention screws from below** | Two M3 screws into brass inserts in the foot keep the arm from walking out. Radial slots in the floor accept any seat position within ±`home_gap`. |
| **MR30 pigtail through the back-wall window** | The motor connector leaves with the arm, so a swap never opens the body. |

## Arm swap procedure

1. Remove the two retention screws from under the socket (2.0 mm hex).
2. Tap the arm outward with the heel of your hand, or push it from inside through the back-wall window
   with a hex key. The self-locking taper needs a deliberate push to release.
3. Slide the arm out. Unplug the MR30 when it clears the socket.
4. Plug in the new arm and slide it in until it wedges. Push firmly; the seat is where it stops, not
   where the back wall is.
5. Refit the two screws, snug only. They retain the arm and do not set its position.

The top plate, canopy and Jetson stay on. Target: under 2 minutes (test plan 2.2).

## Capacities (computed by `arm_model.joint_capacity`, rigid-plastic)

| Link | Model |
| --- | --- |
| Flank bearing (PAHT-CF) | S · (2·flare) · L_t² / 4 |
| Tie bolts | n · min(M3 proof 2.9 kN, washer bearing on PAHT-CF) · L_t / 2 |
| Body box | S · I_box · k / (H/2) |

The governing link must carry `crash_factor` (8) × the limit-load root moment. The design report lists
the margins.

**The fuse ratio** (joint capacity ÷ arm-root capacity) **is below 1, and that is reported, not hidden.** A
stiffness-sized PPA-CF arm is about 25× stronger than its flight loads in quasi-static bending. No printed
socket with M3 hardware can be stronger still, and the earlier bolt-clamp version only looked like it was
(fuse ratio 1.95) because its model left out the fastener path. In a real crash, impact energy and the
brittle PPA-CF notch behavior (6.5 kJ/m² notched) decide what breaks, so test plan 1.4 checks it
destructively. The dovetail's contribution is that the likely failure is in replaceable hardware: tie-bolt
washers crushing, or retention screws pulling. Body layers are not pulled apart, because they are never
loaded in tension.

## Trade-offs vs the previous bolt-clamped tenon

| | Bolt clamp (2 bolts through tenon) | Tapered sliding dovetail |
| --- | --- | --- |
| Play / repeatability | Set by hole clearance (~0.1–0.2 mm) | **Zero, preloaded wedge seat** |
| Holes through the stressed tenon | 2 × Ø3.3 | **None** (insert pilots in the foot only) |
| Swap | 2 bolts top-to-bottom, slide | 2 screws from below, tap, slide |
| Vertical joint stiffness | Full tenon width (top plate) | Flank projected width only, about 3× softer, still ≫ arm |
| Body mass | lighter | **heavier**: ~9 mm socket walls (strut + tie bolt) |
| Print risk | Low | Flank accuracy matters: calibrate with the socket coupon (test plan 0.5) |
