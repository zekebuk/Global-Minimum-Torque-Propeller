# Processed Data

This folder contains small locked processed files used by the clean workflow:

- `locked_aero_summary.csv`
- `locked_aero_summary.json`
- `locked_aero_comparison.csv`
- `mil_bemt_validation_LOCKED.csv`
- `gmt_bemt_validation_LOCKED.csv`
- `design_summary_LOCKED.json`

These files mirror the final thesis package in `results/FINAL_THESIS_USE_THESE/` and preserve the locked modeled comparison. They are processed model outputs, not experimental measurements.

Path fields in these mirrored files are project-relative where practical. The authoritative frozen files under `results/FINAL_THESIS_USE_THESE/` are left unchanged for traceability.
