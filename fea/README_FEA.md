# Final FEA Organization

The final controlled geometry is generated by:

```powershell
python Code/geometry/run_final_geometry.py
```

Final geometry files:

- `results/final_geometry/controlled_mil_geometry.csv`
- `results/final_geometry/controlled_gmt_geometry.csv`

The active MATLAB beam implementation is preserved in its original location:

- `Code/Propeller_3D_Beam_6DOF_FEA/`

A non-destructive copy may also exist under:

- `Code/fea/legacy_3d_beam/`

Use `Code/fea/run_final_fea.py` as the Python-side final FEA boundary. The existing MATLAB scripts still read their configured geometry paths unless explicitly updated, so outputs from older reference or optimizer geometry should be treated as development/debug outputs, not thesis-ready controlled-geometry FEA.

Thesis-ready FEA outputs must explicitly document that they read the final controlled geometry files above. Existing outputs generated from older reference geometry, UI defaults, or raw optimizer geometry are archived/debug only.
